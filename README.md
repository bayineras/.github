# .github

`bayineras` org'unun ortak PR ve issue şablonları. Kendi şablonu olmayan her repoya GitHub bunları otomatik uygular.

- `pull_request_template.md` — her PR açıklamasının başlangıcı
- `ISSUE_TEMPLATE/` — Hata ve Yeni özellik formları

> Bu repo **public**tir (GitHub şartı). Buraya kod, token, müşteri bilgisi ya da iç süreç ayrıntısı konmaz.
